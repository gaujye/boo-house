# 阿飄出沒 · BOO HOUSE

萬聖節打鬼小遊戲：立體卡通鬼屋、四種阿飄、鬼屋風聲、命中音效，以及 60 秒連擊計分挑戰。

## 遊玩

開啟 `dist/index.html`，按「開始捉鬼」，以滑鼠或觸控點擊阿飄。連續命中每 5 隻提升倍率，最高 ×3；點空或讓阿飄逃走會中斷連擊。結算顯示總分、捕捉數量和命中率，最高分保存在目前瀏覽器。

## 技術與部署

原生 HTML、CSS、Canvas 和 Web Audio，無需安裝依賴或建置。Vercel 使用 `vercel.json` 將 `dist` 作為網站根目錄。

程式模擬檢查：`node check.cjs`。

背景是以參考圖風格製作的 AI 生成素材，提示詞見 `ARTWORK.md`。
